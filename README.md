# ai-venture-data

自動収集された公開データのスナップショットを、毎日ここに置いています。

Daily snapshots of publicly available data, collected automatically.

---

## これは何か / What this is

各ディレクトリが1つのデータセットに対応し、その日に観測した値を1ファイルとして
保存しています。**元の情報源が過去の値を保存していないもの**を対象にしています。
つまり、ここにある古いファイルは、他のどこからも取得できません。

Each directory holds one dataset, one file per day. The sources tracked here
publish only a current value and discard the previous one — so the older files
here cannot be obtained anywhere else, including from the original source.

## 使っていいのか / Can I use this

**最新のファイルは自由に使えます**（CC BY 4.0、出典表示のみ）。
過去のファイルの再配布には許諾が必要です。詳細は [LICENSE](./LICENSE) を
お読みください。

The **latest** snapshot in each directory is CC BY 4.0 — use it commercially,
just credit this repository. Older snapshots and compiled time series are not
freely redistributable; see [LICENSE](./LICENSE).

## 正確性について / Accuracy

自動収集で、人間の検証を経ていません。誤りがあり得ます。
気づいた点があれば Issue でお知らせください。

Collected automatically, not verified by a human. It may be wrong. Open an
issue if you spot something.

## 履歴が必要な場合 / If you need the history

過去の時系列データが必要な場合は、Issue を立ててください。

If you need the back-series, open an issue.
